# Data and Reference Sources to Review

The following are *starting points*, not yet analyzed datasets. Check current access terms, definitions, and update dates before use.

1. FAA Runway Safety: https://www.faa.gov/airports/runway_safety
2. FAA Aviation Safety Information Analysis and Sharing (ASIAS): https://www.asias.faa.gov/
3. NTSB Aviation Investigation Search: https://www.ntsb.gov/Pages/AviationQuery.aspx

For each source eventually used, record the exact page/dataset title, retrieval date, dataset period, fields, filters, and limitations. Do not upload copyrighted or restricted source files without permission.
