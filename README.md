# Runway Incursion Safety Analysis

## Project Overview

This repository documents an aviation safety analysis project focused on runway incursions at commercial airports in the United States.

The project explores runway incursion hazards, contributing factors, safety risk assessment methods, and potential mitigation strategies using aviation safety principles.

## Objectives

- Identify runway incursion hazards and contributing factors.
- Examine operational and human factors affecting runway safety.
- Apply structured hazard identification and safety risk assessment methods.
- Explore safety recommendations and preventive measures.
- Demonstrate practical applications of aviation Safety Management Systems (SMS).

## Methodology

The project uses aviation safety analysis concepts, including:

- Hazard Identification
- Safety Risk Management (SRM)
- Safety Management Systems (SMS)
- Human Factors Analysis
- Systems Safety Engineering

## Repository Files

- **methodology.md** — Overview of the safety analysis approach.
- **hazard-register.csv** — Example runway safety hazards and potential mitigations.
- **data-sources.md** — Reference sources for aviation safety research.

## Project Status

**In development.** The initial hazard register contains illustrative examples. Future updates will distinguish verified research findings from hypothetical scenarios and include supporting evidence from public aviation safety sources.
